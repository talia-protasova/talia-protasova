## Hi, I'm Talia

Frontend Engineer.

I'm passionate about things that are easy to underestimate and expensive to fix later: semantic HTML, CSS architecture, and accessibility.

My commercial background is mostly Angular and TypeScript, with Vue 2 and AngularJS along the way. Outside work, I'm exploring Vue 3 through personal projects, experimenting with Svelte, and regularly falling down rabbit holes. Sometimes it's a new feature in a technology I already know; other times it's something entirely new that I'm curious to try.

I like interfaces that make sense twice: when someone uses them, and when another developer opens the code six months later.

That means writing clean, well-structured code that's easy to understand, maintain, and extend. It applies to application logic and component architecture just as much as to CSS that doesn't turn into a specificity contest or keyboard navigation that isn't an afterthought. I'd rather spend time getting things right than leave the next developer to reverse-engineer my intentions from a tangled mess of code.

I've worked on education platforms, healthcare systems, service marketplaces, and complex enterprise applications. The kind of software where "we'll fix it later" usually means someone else gets stuck with it.

Creative pedant. I show up, meet deadlines, and actually care about the people I ship with.
