## Hi, I'm Talia

I like building things that make sense. Not just in the browser, but in how they work, how the pieces fit together, and how easily someone else can understand and maintain them six months later.

My commercial background is mostly Angular and TypeScript, with React, Vue 2, AngularJS, and legacy enterprise systems along the way. I've also worked with applications built on Node.js, Express.js, MongoDB, and InterSystems Caché.

I've worked on education platforms, healthcare systems, service marketplaces, and complex enterprise applications. The kind of software where "we'll fix it later" usually means someone else gets stuck with it.

I'm passionate about things that are easy to underestimate and expensive to fix later: semantic HTML, CSS architecture, accessibility, and the decisions that make software easier to maintain. But I'm just as interested in what happens beyond the interface: how data moves through an application, how different parts of a system work together, and whether the features we build actually solve someone's problem.

I like interfaces that make sense twice: when someone uses them, and when another developer opens the code six months later.

That means writing clean, well-structured code that's easy to understand, maintain, and extend. It applies to application logic and component architecture just as much as to CSS that doesn't turn into a specificity contest or keyboard navigation that isn't an afterthought. I'd rather spend time getting things right than leave the next developer to reverse-engineer my intentions from a tangled mess of code.

I'm endlessly curious and regularly find myself happily falling down rabbit holes of new technologies, unfamiliar concepts, and interesting ideas. Sometimes it's a small detail in something I already know; other times it's an entirely new field I hadn't planned to explore.

**Creative pedant.** I show up, meet deadlines, and actually care about the people I ship with.
